**Student ID:** IT23288058  
**Member:** Member 3  
**Domain:** AI & Computer Vision  

---

## 📌 Component Overview
This component focuses on the automated visual quality control of fabrics[cite: 6]. It consists of two core sub-modules:
1. **Fabric Classification:** Multi-class classification (Cotton, Polyester, Silk) using feature extraction and lightweight ML models[cite: 6, 7].
2. **Defect Detection:** Real-time contour analysis and computer vision processing via OpenCV (and YOLOv8 framework) to detect stains, tears, and physical fabric anomalies[cite: 6, 7].

---

## 🛠️ Tech Stack & Dependencies
* **Language:** Python 3.10+
* **Core Libraries:** `opencv-python`, `numpy`, `torch`, `torchvision`, `ultralytics`, `scikit-learn`, `matplotlib`

---

## 🚀 Features Implemented
* **Live Camera Stream Inspection:** Real-time webcam processing feed capturing physical fabric samples.
* **Contour-Based Defect Bounding:** Isolate defect regions with red bounding boxes and calculate surface anomaly area.
* **Standardized JSON Schema:** Structured output payload formatted for Node-RED pipeline storage and Frontend dashboard visualization.
